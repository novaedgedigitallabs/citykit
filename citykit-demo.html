Package Features

search()
Name-based city search with partial matching and smart prefix/exact sorting.
search("Delhi")
fuzzySearch()
Typo-tolerant city search using Levenshtein distance thresholds.
fuzzySearch("Nwe Yrok")
nearest()
Find the closest city or list of cities to any coordinates on Earth.
nearest(28.61, 77.20)
distance()
Calculate exact Haversine distance in both kilometers and miles.
distance(28.61,77.20, 40.71,-74.00)
byContinent()
Retrieve and filter cities across any of the 7 global continents.
byContinent("Asia")
byPopulation()
Filter and query cities matching a specific population range.
byPopulation({ min: 1000000 })
stats()
Get database analytics, population summaries, and size stats.
stats()
random()
Instantly extract a random city from the global database.
random()
